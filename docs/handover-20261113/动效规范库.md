### 全局动效开关（改设计前必读）

- 页脚右下角有「**动效：开启 ◉**」按钮（`#motion-toggle`）：关闭时给 `body` 加 `.motion-off`，所有动效**直接定格终态**（内容完整可见，不隐藏）。
- 同时尊重系统 `prefers-reduced-motion: reduce`。
- 因此"看不到动画"时先查两处：该开关状态、系统减少动效设置；不是动效坏了。
- 任何新加动效**必须**沿用这两条兜底（`.motion-off` / reduce 下落到终态），否则关闭动效后内容会消失。

## 四、各动效详情

> 每条按「效果 → 用法 → 参数 → 已落地 → 注意」组织。通用件统一约定：`<link>` 引 css + `<script>` 引 js，给元素加类即用；`prefers-reduced-motion` / `body.motion-off` 时全部直接显示终态。

### M-01 · 弹出（Pop-In） `.pop-in`

**效果**：元素滚入视口时，从自身中心由 `scale(0)` 放大到原尺寸，像从页面里"弹出来"。全程不透明（不淡入）、无位移、无旋转，700ms 收尾减速，只播一次，滚回不重播。

**用法**：
- 内页通用：`<link href="assets/css/pop-in.css">` + `<script src="assets/js/pop-in.js">`，元素加 `class="pop-in"`。
- 组错峰：容器加 `class="pop-group" data-pop-step="70"`，组内 `.pop-in` 按 DOM 顺序 70ms 递进（变体 M-01+D）。
- 首页另有 `column-home.js` 的 `run(container, items, STEP)` 通用触发器（awards / payment-logos / media-line 三处复用）。

**参数**：触发 = 自身顶边到视口 90%；700ms；`cubic-bezier(0.5,1,0.89,1)`（power1.out）；原点居中；播放 1 次。

**变体**：

| 变体 | 差异 |
|---|---|
| `M-01+F` | 追加淡入（opacity 0→1） |
| `M-01+R` | 追加旋转 20°→0（或元素自身静态角→静态角），1000ms，power2.inOut |
| `M-01+D` | 组错峰 60–80ms/项 |

**已落地**：

| 位置 | 变体 |
|---|---|
| 首页 `#markets` 四张地图浮标卡 | M-01+R（终点保留各自倾斜角 -5/4/3/-5deg） |
| 首页 `#awards` 六枚奖章 | M-01+D（70ms） |
| 首页 `#funding` 支付 logo 三枚 | M-01+D（70ms） |
| 首页 `#funding` 入金/出金两张卡 | M-01+R |
| **33 个内页底部 CTA 横幅** | M-01 单块 |
| about 页奖章墙六枚 | M-01+D（pop-group 70ms） |
| 账户类型页「6 大权益」六张卡 | M-01+D（pop-group 70ms） |

**注意**（关键坑）：
1. 目标元素不能已有 transform；带静态倾斜的用 M-01+R 且终点取该角。
2. 动画结束必须加 `.pop-done` 让初始隐藏规则失效，否则 hover 的 transform 全部失效。
3. `animationend` **不能用 `{once:true}`**——子元素动画结束冒泡上来会截胡，必须判断 animationName 后手动移除。
4. `scale(0)` 元素的 IO 判定按缩放后盒子，触发点实际提前约半个身位，一般无碍。

### M-02 · 打字出场（Type-In） `.type-in`

**效果**：区块滚入视口时按「小标签上移 → 大标题逐字（从放大态收进原位显影）→ 正文逐行（从遮罩下顶上来）」三段依次成型，像有人从左到右飞速打字。不是打字机光标，无随机字符。整段约 1.3s，只播一次。

**用法**：
```html
<div class="kicker type-in-eyebrow">Which One</div>
<h2 class="sec-title type-in" data-type-in="chars">如何选择您的账户</h2>
<span class="sec-sub type-in" data-type-in="lines">选择取决于您的启动资金与交易目标</span>
```
文件：`assets/css/type-in.css` + `assets/js/type-in.js`。`data-type-in="chars"` 逐字（标题）、`"lines"` 逐行（正文）；标签用 `.type-in-eyebrow` 单独挂。

**参数**：触发 = 区块顶边到视口 90%；每段 500ms；标题错峰总量恒 500ms 摊到全部字（长标题自动压到 11ms/字）；正文每行 +50ms、680ms 起播。

**变体**：

| 变体 | 用法 |
|---|---|
| `M-02` | 全套三段（section 头标准用法） |
| `M-02-C` | 只标题逐字 |
| `M-02-L` | 只正文逐行 |
| `M-02+W` | 标题逐词（英文场合用） |

**已落地**：

| 位置 | 用法 |
|---|---|
| 首页各 section 头 | 全套三段 |
| 账户类型页 5 个 `.sec-head` + 底部 CTA `h2`/`p` | 全套三段；HERO 不挂 |
| about 页「权威奖项与媒体」区标题组 | 全套三段 |
| 22 个内页 FAQ 区标题 | 营销页 11 页全套；文档页 11 页只 `M-02-C` |

**注意**（关键坑）：
1. **含内联标签（`<em>/<b>/<a>`）的标题不能挂**——拆字会把标签展平丢样式；要动画带样式片段，把 `.type-in` 挂到该内联元素自身。
2. 中文标点必须并入前一个字（组件已处理）；英文标题 14 字以上建议逐词。
3. 只对首屏以下区块用；hero 逐字影响观感与 LCP。
4. 与 M-01 分工：M-02 管文字、M-01 管物件；同一元素不要挂两套。

### M-03 · 滚动展开（Scroll-Unfold） `.js-unfold`

**效果**：媒体块随滚动进度从 0 宽向两侧摊开到满宽——窄时只看到画面中心被 `object-fit:cover` 放大裁切的一块，越滚越宽、逐渐还原构图；上滚等速收回至消失。与滚动严格 1:1（linear + scrub 0.8 平滑），双向可逆。

**用法**（标准版，纯图片）：
```html
<div class="unfold-wrap js-unfold" style="height:50rem">
  <a class="unfold" href="#"><img src="cover.webp" sizes="100vw" alt=""></a>
</div>
```
文件：`assets/css/scroll-unfold.css` + `assets/js/scroll-unfold.js`（站点内通用件为内容型实现，见 M-03+C；标准版需自行写 `width` 动画，参数同上，不要用 `scaleX`）。

**参数**：起点 = 容器顶边贴视口底（`top bottom`）；终点 = 容器 30% 线到视口 50% 线；`width 0%→100%` linear；scrub 0.8s；双向。

**变体**：`+V` 宽高同开（方形卡）｜ `+R` 圆角渐现 ｜ `-N` 不 scrub，一次性 700ms ｜ `-S` 只开不收 ｜ `+C` 内容型（见下）。

**已落地**：当前站点标准版暂无落地（首页市场卡原用 M-03+C，已替换为 M-06）；M-03+C 落地见下。

**注意**（关键坑）：
1. 必须动画 `width`，不能用 `scaleX`（横向变形）或 `clip-path`（变窗帘，失去中心放大感）。
2. 容器高度必须固定；图片必须 `width/height:100% + object-fit:cover`；`srcset` 必须带 `sizes="100vw"`。
3. 首帧直接算到位，不要让已在视口内的图"重新长一次"。

### M-03+C · 滚动展开·内容型 `.unfold.js-unfold`

**效果**：与 M-03 同节奏（滚动 1:1、scrub 0.8、双向），但**只做 `clip-path: inset(0 S 0 S)` 中心裁切**——版式零重排、文字不变形，观感是"卡片从中间被拉开"。用于卡片/面板等含文字的块；代价是中间帧文字会被裁成半句。

**用法**：
```html
<div class="unfold js-unfold">
  <div class="任意内容块">…</div>
</div>
```
文件：`assets/css/scroll-unfold.css` + `assets/js/scroll-unfold.js`（通用，包一层即复用）。

**已落地**：

| 位置 | 备注 |
|---|---|
| 首页页尾 `#start` final-cta 整段 | 实测 1440×744 下裁切进度与线性公式吻合；tab 切换高度变化自动跟随 |

**注意**：外层与原元素同宽、不加 padding；不要同时写宽度动画；脚本失效时不写 clip-path（内容照常全显）。

### M-04 · 飞入（Fly-In） `.fly-in`

**效果**：元素从右侧 220px 外以 opacity 0 飞入原位，900ms `expo.out` 快进缓停。多枚并排加 `M-04+D` 错峰 70ms，可逆序（最右先入）形成"从右往左"的推进波。

**用法**：
```html
<div class="press-line fi-group" data-fi-step="70" data-fi-order="reverse">
  <img class="fly-in" src="…" alt="">
  …
</div>
```
文件：`assets/css/fly-in.css` + `assets/js/fly-in.js`。

| 属性 | 说明 |
|---|---|
| `.fi-group`（容器） | 组触发 + 自动 `overflow:hidden` 防横向滚动条；`data-fi-clip="none"` 可关裁剪 |
| `data-fi-step="70"` | 组内按 DOM 顺序递进 |
| `data-fi-order="reverse"` | 逆序（最右先入） |
| `data-fi-dir="left\|up\|down"` | 改方向，默认 `right` |
| `data-fi-shift="160px"` | 改距离，默认 220px |

**变体**：`+D` 错峰 ｜ `+L` 从左飞入 ｜ `+V` 从下方飞入 ｜ `+B` 带轻微模糊。

**已落地**：

| 位置 | 变体 |
|---|---|
| 首页 `.media-line` 媒体关注 5 枚 logo | M-04+D 逆序 |
| about 页媒体行 5 枚 logo | M-04+D 逆序（通用件 fi-group 写法） |

**注意**：
1. 位移量上限 = 相邻列间距，超了会压到邻居。
2. **IO 裁剪自锁坑**：初始位移被容器 `overflow:hidden` 裁掉后元素永不 intersecting——组件在有 `.fi-group` 时改为观察组容器，不要改回观察元素自身。
3. 兜底计时必须跟 900ms 实际时长，复用 M-01 的 700+250 会截断尾帧。

### M-05 · 方位移入（Slide-In） `.slide-in` + `data-dir`

**效果**：内容块从指定方位以 opacity 0 + 自身尺寸 60% 的位移移到原位，500ms `power1.out` 落位减速；组内错峰总量 0.4s 依次进场。不缩放、不旋转、不过冲，是最克制的入场——文字块轻轻"浮"到位。触发 = 组顶边到视口 90%，播一次，不 scrub。

**用法**：
```html
<div class="某容器 si-group">
  <div class="某块 slide-in" data-dir="bottom">…</div>
  <div class="某块 slide-in" data-dir="bottom">…</div>
</div>
```
文件：`assets/css/slide-in.css` + `assets/js/slide-in.js`。`data-dir` 是**"从哪个方位进场"**：`bottom`=自下向上（源站默认）、`top`/`left`/`right` 同理。全组同向（R1）就逐个写 `data-dir`；不写则按 R2 轮转 下→左→右→上。

| 属性 | 说明 |
|---|---|
| `data-si-shift="120px"` | 整幅宽块（>620px）固定位移，防止 60% 自宽过大 |
| `data-si-total` | 覆盖组错峰总量（默认 400ms） |

**变体**：`+S` 无淡入 ｜ `+K` 带微缩放 ｜ `+L` 长距（220px/900ms，近 M-04） ｜ `+Z` 反向错峰。

**已落地**：

| 位置 | 方向 | 参数差异 |
|---|---|---|
| 首页 `#trust` 三张信任卡 | bottom | 默认 60%/500ms/133ms 递进 |
| 首页 FAQ 五条 | right | `data-si-shift="120px"`，step 100ms |
| 账户类型页「三种账户」三张大卡（M-07 底板上） | bottom | `data-si-shift="150px"`（卡高 730px，60% 过大） |
| 账户类型页「如何选择您的账户」三栏 | bottom | 默认 60%（≈90px），step 200ms |
| 账户类型页「安心交易 · 多重保护」三栏 | bottom | 同上 |
| 22 个内页 FAQ 列表 | right | `data-si-shift="120px"`，step = 400/(n−1) |

**注意**：
1. 位移用百分比（自身 60%）保持任何尺寸同一观感；整幅宽块用 `data-si-shift` 固定值。
2. 只做 opacity + translate，叠加 scale/rotate 就变成 M-01/M-04 了。
3. 元素自身不能已有静态 transform；动画结束 `.si-done` 让位给 hover。
4. 首屏 hero 不要用；不要做成 scrub（跟滚动的是 M-03/M-06）。

### M-06 · 后仰扶正（Tilt-Up） `.js-tilt-up`

**效果**：大图一开始像上边往后倒了 45°（带真实透视近大远小）、整体抬高 30%；随滚动一边立正回平面一边落回原位，滚到视口中线附近完成。上滚原路倒回。只由滚动驱动（linear + scrub 0.8），不自己播，双向可逆。

**用法**：
```html
<div class="tilt-stage">              <!-- 提供透视的壳 -->
  <div class="js-tilt-up">…大图/产品截图…</div>
</div>
```
文件：`assets/css/tilt-up.css` + `assets/js/tilt-up.js`。可覆盖：`data-tu-angle="30"`（起始角）、`data-tu-drop="-18"`（上抬量 %）。

**参数**：`rotateX 45°→0` + `translateY −30%→0`；父级 `perspective:1000px`；起点 `top bottom`、终点 `30% 50%`；scrub 0.8；双向；无 opacity/scale。

**变体**：`+Y` rotateY（左右转正） ｜ `+S` 叠加缩放 ｜ `+N` 不 scrub 一次性 700ms。

**已落地**：

| 位置 | 备注 |
|---|---|
| 首页 `#markets` 市场大卡（原 M-03+C 替换而来） | 宽 1280 大卡的横向溢出已按「桌面 `html.js{overflow-x:hidden}` + ≤767 `.tilt-stage{overflow-x:clip}`」处理 |

**注意**：
1. **父级必须有 perspective**，否则 rotateX 退化成纵向压扁。
2. 触发位置必须用 `offsetTop` 链算，**不能用 `getBoundingClientRect().top`**（自身带 3D 变换时包围盒漂移，会自反馈抖动）。
3. 宽块（接近视口宽）45° 时包围盒横向撑大约 1.3 倍，会出横向滚动条——按上面已落地的裁剪方案处理，不要在 `.tilt-stage` 统一裁（会把圆角切成直边）。
4. 与 M-03 同节奏但动 3D 倾角，两者不要叠同一元素。

### M-07 · 极光白卡（Aurora Bento）

**效果**：彩色极光底板（10 个模糊彩色椭圆的 SVG）+ 不透明白卡铺满，彩色只从卡片缝隙与外沿透出，形成"卡浮在彩色底上"的层次。参考站另配套四条子动效（A 卡片自下而上 30% 淡入 / B 卡内配图下落 / C 小浮卡往复浮动 / D 箭头悬停旋转），**本站均未启用**——落地时入场统一改用 M-05 或 M-01+D，见下方已落地表。

**用法**：底板图 `assets/img/aurora-mesh.svg` 直接引用：
```css
.band {
  background-color:#F3F4F6;
  background-image:url(../img/aurora-mesh.svg);
  background-size:170% auto;          /* 放大倍数是关键，见下 */
  background-position:50% 45%;
}
```

**已落地**：

| 位置 | 底板 | 入场动效 |
|---|---|---|
| 账户类型页「三种账户」三张大卡 | 170% | M-05（bottom 150px） |
| 账户类型页「6 大权益」六张卡 | 108% | M-01+D |

**注意**：
1. **放大倍数取决于容器宽高比**：接近 2:1 的容器用 170%+；宽扁容器（≥3.5:1）用 108%。判据：缝里出现**纯色**=放太大，出现**灰白**=落在留白区（cover/contain 会落到留白，基本无色）。
2. 卡片必须完全不透明白底；桌面不加阴影（极光透缝已是"发光边框"），窄屏才补阴影。
3. 卡片 hover 位移用 `translate` 属性，不用 `transform`（避免与入场动画打架）。
4. ≤479 单列时建议整体关掉底板图。

### M-08 · 翻页（Page Flip） `hsbFlip()`

**效果**：容器换内容时，旧内容绕**顶边**向前翻倒、压扁并淡出（280ms），随后新内容从上方翻平落下（340ms）；行数变化时高度以 380ms 过渡补齐。像撕掉一页再落下一页。用于筛选 chip、分组切换、分页。

**用法**：
```js
window.hsbFlip(el, function () { /* 换内容回调 */ }, { out: 280, in: 340, angle: 88 });
```
文件：`assets/js/flip.js`（通用件，无 CSS）。脚本负责锁高度 → 翻出 → swap → 高度过渡 + 翻入 → 释放；`prefers-reduced-motion` / `motion-off` 直接换内容。

**变体**：`+U` 反向向上翻走 ｜ `+X` 横向翻（rotateY，宽扁内容慎用）。

**已落地**：

| 位置 | 备注 |
|---|---|
| 财经日历页「全部 / 高 / 中 / 低影响」筛选 | `economic-calendar.html` 内联脚本调 `hsbFlip(.tbl-wrap, swap)`；`__flipBusy` 防连点 |

**注意**：
1. **不要加 perspective**——带透视时 88° 会横向放大 1.2–1.5 倍，表格边缘被裁掉半字；平行投影零裁切。
2. 高度必须锁（否则行数变少的第一帧整块塌缩）。
3. 必须防连点（`__flipBusy`），否则出现"按钮已高亮、内容还是上一批"的错位。

### M-09 · 渐变填充悬停（Gradient Fill Hover） `.fill-hover`

**效果**：卡片默认自身底色；鼠标移入时一层彩色渐变**自顶部向下逐段揭开**铺满整卡，标题与箭头先转白、正文随后转白；移出时渐变退走、正文先恢复深色、标题最后恢复。节奏"自上而下刷下来"。

**用法**：
```html
<link href="assets/css/fill-hover.css" rel="stylesheet"/>
<a class="my-card fill-hover" href="…"> … </a>
```
`.fill-hover` 只管填充+换色；卡片底色/圆角/内距由业务样式自己写。

**参数**：填充 = `clip-path: inset(0 0 100% 0) → inset(0)`，550ms `cubic-bezier(.3,.85,.35,1)`；标题换色进入 delay 60ms / 退出 170ms；正文进入 200ms / 退出 40ms（分块延迟，反序退出）；默认态底色 `#F5F3EB`。

**色带两套**：

| 组 | 色带 | 场景 |
|---|---|---|
| **A · 蓝→绿（当前采用）** | `#1E5CD2 → #1C67CC → #1A73C6 → #177FBD → #158BB5 → #1599AA → #15A6A0 → #15B395 → #14BF8B` | 与站点主按钮同色相；采样自「下载 APP」按钮并压深一档（声明值亮度过高，白字对比度不足） |
| B · 黄→粉紫→蓝（参考站原色） | `#FCF939 → #DCA2B8(22%) → #B99BE5(34%) → #9A9EF3 → #5DB3FF → #48BDFF` | 需求指名参考站原色时用；扁卡要压缩黄段 |

**变体**：`+U` 自下而上 ｜ `+L` 自左向右（宽扁横幅） ｜ `+S` 整层滑入（参考站原做法，接受颜色跳变）。

**已落地**：

| 位置 | 备注 |
|---|---|
| 首页 `#trust` 三张信任卡 | `a.trust-card.fill-hover`；外观在 `home-minpilot.css`；色带 A 组蓝→绿 |

**注意**：
1. **不要用 translateY 整层滑入**——中间帧露出图层下半段，颜色会跳；必须 clip-path 揭开（像素与渐变位置固定对应）。
2. 换色必须分块延迟（进 60/200ms、出反序 40/170ms），否则白字压浅底 100–200ms 看不见。
3. hover 必须包在 `@media (hover:hover)` 里（触屏残留），键盘用 `:focus-visible` 单独覆盖。
4. 双类提权 `.fill-hover.fill-hover:hover` 压过站内同特异性规则。

### M-09-B · 按钮渐变瞬切（M-09 派生）

**效果**：按钮 hover **瞬间**变成蓝绿渐变实心 + 白字（面积小、要求"直接变成"，不做揭开动画），离开恢复原样。底色瞬切，用 `box-shadow .30s` / `color .18s` 过渡衔接。

**实现**：纯 CSS 限定选择器（账户类型页 `site-light.css` 末尾，`[data-page="account-types"] .trade-account-comparison .acct .btn-outline`），渐变 `linear-gradient(90deg,#1E5CD2,#1A73C6 30%,#1599AA 62%,#14BF8B)`。

**已落地**：账户类型页三张账户卡「立即开户」按钮。

**注意**：
1. `background` 简写末尾必须写**两个 `border-box`**（origin + clip），否则 2px 边框区由渐变末色补齐、hover 时露绿边。
2. specificity (0,6,0) 只作用于本页，不污染全站次按钮。
