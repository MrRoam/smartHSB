# HSB Kita 官网 · 设计约束摘要（交接用）

> 用途：**只改设计、不改内容**时的最小约束集。摘自 `2026-11-02_项目要求汇总.md`（第 3/4/5/6/10/11 节），完整口径以原文档为准。
> 配套：`website/`（站点本体）+ `2026-11-12_动效规范库.md`（动效编号与落地位置）+ `2026-11-13_站点改动清单_交接用.md`（我方已改过什么）。
> **本轮边界**：只动视觉，不动文字、数字与排列顺序；确需改动请先回问。

### 开工前先知道的三件事

1. **两套样式体系并存**：首页 `home-minpilot.css` + `column-home.*`；34 个内页 `site-light.css` + `subpages.*`。改内页不会命中首页样式。
2. **全局动效开关**：页脚右下「动效：开启 ◉」关闭后所有动效定格终态（内容照常可见），且尊重系统减少动效设置——看不到动画先查这里。
3. **缓存版本号**：页面引用的 `?v=` 后缀是手动版本戳，改动 css/js 后必须同步改对应页面里的版本号，否则浏览器吃旧缓存、改了看不到效果。

---

## 一、三条铁律（最容易在设计改动中破坏）

1. **不重排品种顺序**：4 大类 25 品种固定「贵金属(2) → 股指(5) → 外汇(17) → 能源(1)」，标签页、卡片、表格行、正文枚举一律同序。做视觉分组、调网格列数都不能打乱。
2. **不改数字写法**：金额一律印尼写法 `Rp400.000`（点号千分位），全站禁用「万 / 千 / 百万」中文数位；汇率唯一基准 `1 USD = Rp16.000`。
3. **移动端不加内联 `grid-template-columns`**：内联样式优先级压过媒体查询，会直接造成窄屏溢出；grid 一律写 `minmax(0,1fr)`。

---

## 二、色与数据呈现

- **涨绿跌红**（印尼惯例，与国内相反）；行情条标注「涨绿跌红 · UTC+7」。
- 币种展示用 **USD**；出金上限等同给 USD 与 Rp 等值（按 16.000 折算）。
- 时区写 **UTC+7（WIB）**，不写 GMT+7。
- 印尼语版本金额用 `Intl.NumberFormat('id-ID')` 格式化，禁止机翻数字。

## 三、品牌与法律实体（设计稿里写字时）

- 品牌：**HSB Kita / Teman Trading Kamu**；**非** HSB Investasi。
- 法人：**PT Handal Semesta Berjangka**（Semesta，无点号；写成 Semasta 为错）。
- 页面不得出现「内容取自官网 / 待核对 / 占位 / 演示 / 示例 / 待接入」等制作状态标注（保留：法律效力条款、转账核对提示、活动「即将上线」标签、合规术语）。

## 六、合规图形与表述（动到资质/奖项区时）

- **A+++ = BAPPEBTI 定期评级**（每 3 个月复评，2026 Q1 最高等级），**不是一次性认证或终身牌照**；文案须含「定期评级 · 每 3 个月复评 · 以官方公告为准」。
- 监管口径：**3 家监管机构（BAPPEBTI / OJK / BI）+ 3 家会员资格（ICDX / ICH / ASPEBTINDO）**，不写「6 家监管」。
- ICDX 奖项写「**连续 6 年获奖（2021–2026）**」；客户资金保险写「**客户资金保险**」（不是"入金保险"），`$1,000,000（≈Rp16.000.000.000）`。
- 证书类图形**一律手绘 SVG 示意、注明"非官方证书"，不得出现印章 / 签名 / 徽号**。
- 许可证页区块顺序：监管机构牌照 → 行业奖项 → ISO/IEC 27001；奖项数据顺序：A+++ 评级 → 6 年连续获奖 → 20+ 项行业荣誉。
- **增删图标的数字联动**：媒体 logo 增删改须同步改文案「5 家主流财经媒体」；奖章增删须同步「6 枚 / 2021–2026 / 20+ 项行业荣誉」。数字不可与图标数量脱节。

## 七、动效引用规则

- 动效一律按 `2026-11-12_动效规范库.md` 的编号引用（M-01 弹出 / M-02 打字 / M-03 滚动展开 / M-04 飞入 / M-05 方位移入 / M-06 后仰扶正 / M-07 极光白卡 / M-08 翻页 / M-09 渐变填充），**不擅自新造参数或改节奏**。
- 通用件已是独立 css/js（`pop-in` / `type-in` / `slide-in` / `fly-in` / `flip` / `fill-hover` / `scroll-unfold` / `tilt-up`），加类即用，不要复制到业务样式里重写。
- 动效关闭条件必须保留：`prefers-reduced-motion` 与 `body.motion-off` 下直接显示终态。
