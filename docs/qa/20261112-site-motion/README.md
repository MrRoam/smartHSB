# 首页修复与全站浅色动效统一 · 2026-11-12

本轮覆盖正式首页与 34 个内页，不改独立设计参考页。参考 https://minpilot.webflow.io/ 的柔光、产品浮层与大字页脚，沿用已确认的蓝、青、薄荷绿和浅色底。

## 已实现

- 首页六年荣誉桌面单行；窄屏保持单行，使用可聚焦的横向滚动区域，不自动滚走信息。
- 手机从倾斜状态平滑摆正，移开后恢复；下载页产品场景同步采用悬停反馈。
- 页脚 SmartHSB 使用蓝绿流光，所有业务内页同步使用。关闭动效或系统减少动效时显示静态深绿字。
- 内页专属 CSS 的旧灰蓝色值改为语义色板，新增共享浅色主题。统一首屏柔光、标题、按钮、信息表格、操作面板、导航与页脚；保留业务正文、警告语义色和原图片内容。
- 保留原图表绘制、资金路线、学习步骤、蜡烛图等动效，补充浮层、条形图、列表错峰、Tab 和 FAQ 过渡。内容默认可见；循环离屏、后台暂停；所有新增动效响应统一开关与系统设置。
- 修复内页手机导航溢出、下拉菜单键盘焦点、手动动效偏好被系统变化覆盖、表格键盘访问和页脚低对比度。

## 验证

- 35 页 × 320 / 390 / 768 / 1024 / 1440px，共 175 个布局用例，无页面横向溢出或主文案越界。荣誉六项处于同一行。
- 23 个交互用例通过：手机悬停、流光的可见/离屏状态、手动开关、系统减少动效与偏好保留、移动菜单、方向键导航、17 项外汇长列表、FAQ、帮助搜索与品种搜索。
- 35 页的系统减少动效状态均无运行中的动画，开关显示系统已关闭。
- 320px 无脚本副本：首页、关于、下载、帮助的正文可读，无横向溢出；首页完整 25 个品种可读。测试副本已删除。
- axe-core 4.10.3：35 页 × 390 / 1440px，共 70 次扫描，0 已判定违规。渐变/复合背景仍有需人工判断项；人工核对了白色/薄荷/浅蓝表面、深色正文和主行动的对比度及截图。装饰性流光不承载正文信息。
- 按 Web Interface Guidelines 复核焦点、键盘、动效取消、静态回退及滚动容器。下拉菜单根因是通配过渡延迟了 visibility 更新；在原 CSS 仅过渡 opacity/transform 后，同一键盘事件可正确移动焦点，无额外定时补丁。
- 模拟后台事件时，循环动画停止、原视频暂停；原光门的有限收尾过渡保留。这是事件模拟验证，不是实际设备后台测试。
- 3,655 个本地页面/资源引用存在；根目录镜像与发布首页一致；全部 JS 语法、CSS 解析与差异空白检查通过。变更资源引用使用内容哈希。
- 所有原业务正文按顺序比对一致，仅内页增加装饰性 SmartHSB 字样。光门 CSS、JS 和 MP4 的指纹与任务开始时一致。
