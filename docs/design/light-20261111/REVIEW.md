## 视觉与内容

- 常规内容以白、柔白、浅薄荷、冰蓝为主。光门是明确保留的深色例外。75/15/8/2 是浅色内容的构图建议，没有做像素占比认定。
- 产品舞台的光集中在右侧，文案区保持浅色；市场区使用实色白面。未使用标题渐变字、整页玻璃卡、背景流动或多组循环。
- 场景一保留原光门实拍：门、人物、原文案和六徽章。原视频已在本轮浏览器解码（readyState 4）；没有为预览重写视频或动画。
- 平台示意中的模拟资金和报价来自原首页，屏内及屏外均有示例说明。市场区的分类、25 个名称/报价/涨跌和代表图表数据来自原 HTML/JS。正负值同时有符号，不只靠颜色。
- [内容盘点](evidence/content-inventory.json) 确认贵金属 2、股指 5、外汇 17、能源 1；六徽章、六年奖项、五媒体和五项 FAQ。其余账户、监管、资金隔离、支付/保险条件、积分活动、运营信息和风险披露在 [规范第 6 节](SPEC.md) 逐项安排。
- 其余区块尚未画成完整新首页，不能据这三个场景断言整页内容已完成设计回归。当前正式内容完整保留，由文件指纹核对：128 个正式文件无变化。

## 动效及失败降级

- 默认静态，动画数为 0。用户开启后桌面仅一张浮卡循环，8px / 6s。
- 已观测持续循环在离屏后暂停；关闭总开关后动画数回到 0，内容显示最终状态。
- 系统减少动效时动画数为 0，开关显示系统状态并禁用。手机浮卡回文档流；≤767px 不运行循环。
- 后台暂停的 visibilitychange 处理已通过模拟 hidden 状态测试；真实浏览器后台/操作系统挂起未做跨设备现场验证。没有把“切回前台后正常”当作“后台全程暂停”的独立证据。见 [motion.json](evidence/motion.json)。
- 失败降级使用**同一 HTML 仅去掉外部增强脚本的副本**检查，没有把网络拦截成功写为证据。320px 时全部 25 品种、四组标题及导航可见，无溢出，原生 FAQ 仍可用，失效的动效按钮隐藏。见 [script-failure.json](evidence/script-failure.json) 与 [可查看副本](evidence/script-failure.html)。
