# SmartHSB 浅色视觉方案 · 审阅版

设计日期：2026-11-11；复核完成：2026-11-12，北京时间。状态：**设计审阅稿已公开，首页未实施**。

打开 [视觉审阅稿](index.html) 或 [桌面/手机静态画板](boards.html)。它是独立的设计样张，不是替换首页。正式首页、根目录镜像、现有 CSS/JS、原视频均未修改。

## 1. 方向与关键决定

以白色建立阅读秩序，以薄荷和冰蓝划分内容层次，以亮绿引导主要行动。产品展示承担主要视觉重量。金融信息依靠清晰的文字、数字、边界和条件建立可信度。

| 决定 | 解决的问题 | 本稿如何表现 |
| --- | --- | --- |
| 常规内容区全面浅色 | 连续深底使信息显重，弱化产品细节 | 白 → 薄荷光白 → 白色产品舞台 → 冰蓝市场区 → 白/柔白信息区 |
| 原光门保留炭黑舞台，浅色从其后开始 | 原视频、人物和雾以明暗关系成立；白底直接参与 screen 合成会洗白画面 | 场景一展示原光门真实静帧，下一内容区在独立浅底上开始；光色不盖住徽章 |
| 平台区产品占约 55% 的横向空间 | 参考站的层次来自产品比例，不能只换背景色 | 桌面文案左、产品右；手机文案在前，产品完整置于下方 |
| 市场区回到实色白面和清晰列表 | 行情、名称、条件需要稳定阅读 | 冰蓝外底、白面板、深绿选中态；四类共 25 品种全部可切换 |
| 只保留一处虹彩次按钮 | 彩边过多会与主行动竞争 | 平台区的“试用模拟账户”；其他次行动用文字链接 |
| 新内容区只演示一组持续浮动 | 同时运动会分散读者对行情与条件的注意 | 桌面仅模拟账户浮卡；手机关闭；渐变均静态 |

**本稿推荐的是“浅色内容 + 保留原光门”的方案。** 这不等于全浅色光门已经解决。若要求首屏本身也完全浅色，需要先确认下述合成研究方向，再实施。

### 光门为什么不能只改背景

实际源码 `website/assets/js/intro-portal.js` 的 `drawVideoScene()` 先填纯黑，绘制视频并镜像去除内嵌文字，再用黑色侧缘、顶部和底部遮罩消隐；最后以 `globalCompositeOperation = 'screen'` 叠加 `#1B1B1B`。`intro-portal.css` 也以此炭黑为舞台底色。

screen 每通道公式为 `1 − (1 − 源) × (1 − 底)`。当参与合成的颜色为白色时结果恒为白色。仅改容器 CSS 不会改变 Canvas 中已绘制的黑色；把最终 screen 色改成白色则会抹去图像。两种改法均不成立。

本稿没有对视频反色、覆盖浅色大蒙层或替换人物。原门、人物、文案、视频、时序及六徽章由现有页面真实静帧表达。蓝绿光带放在下一内容区的顶部，保持两个场景各自清晰。

**待研究的全浅色光门方向：** 原视频不变，在独立实验中重建明暗分离及羽化蒙版，限制调色只影响环境和边缘，保留门光与人物剪影。需逐帧核对 0.05 / 1.5 / 3 / 4.5 / 6.0 秒，以及五档宽度；检查内嵌文字移除、雾边、倒影、人物和徽章。当前仅提出研究路线，未制作或验证此版本。若无法同时保留门光层次与原画面关系，继续采用本稿的原光门方案。

## 3. 色板与语义

面积起点：**75% 白/柔白、15% 浅蓝/浅薄荷、8% 绿青强调、2% 功能蓝及补色**。仅用于浅色内容构图；不将保留的光门面积算入此比例，也不把它声称为实测结果。每区块一个主强调色，最多一个辅助色；柔光混色与虹彩边框作为有限的装饰配方例外，不承担状态语义。

| 颜色 | 建议位置 | 搭配底色 / 文字 | 禁止混用 |
| --- | --- | --- | --- |
| 白 `#FFFFFF` | 主阅读面、市场列表、普通卡 | 深墨标题、灰正文、深绿链接 | 不靠白面与柔白面的微小差异单独表达可操作状态 |
| 柔白 `#F6F6F6` | FAQ、运营信息和披露背景 | 深墨 / `#606062` | 不让风险说明变成更浅的灰字 |
| 浅薄荷 `#F1FFF7` | 选中底、模拟账户面、局部信息区 | 深墨 / 深绿 | 不以浅薄荷底单独表示 Tab 已选，需深绿描边和语义 |
| 冰蓝 `#EEF5FF` | 市场外底、功能区分层 | 深墨 / 灰正文 | 不和浅薄荷交错成每行彩色条纹 |
| 荧光草绿 `#97F05E` | 主按钮 hover、图形高亮 | 白/浅薄荷上作图形；填色上用深墨字 | 小白字；与柠檬绿、薄荷青同时抢主行动 |
| 柠檬黄绿 `#BFFF37` | 平台主 CTA、产品右侧光源 | 深墨字；按钮配深绿 1px 轮廓 | 白字；把行情涨幅或监管状态都染成柠檬绿 |
| 薄荷亮青 `#5BFFC3` | 产品中部柔光、按钮按下态 | 深墨字；在白底作装饰 | 小白字；用作浅底正文链接 |
| 翡翠绿 `#01A66B` | 品牌图形、柱形辅助序列、图标 | 实色面配深墨字 | 常规小白字；浅底小号绿字 |
| 科技蓝 `#235DFE` | 下载/工具等功能行动、键盘焦点 | 白字按钮；浅底可用蓝字 | 同一区块再加一个蓝色主 CTA，与亮绿主行动竞争 |
| 电光青 `#00E5E0` | 单个局部小光点，≤15% 装饰透明度 | 仅产品边缘，不承载文字 | 链接、正文、涨跌、按钮主填色 |
| 深绿 `#006C45` | 浅底文字链接、选中标签、正向值 | 白/柔白/浅薄荷/冰蓝 | 整页文字都用绿；用亮绿代替它写正文 |
| 深墨 `#1D1D1F` | 标题、关键数字、亮色按钮字 | 四种浅底及所有亮绿/青填色 | 大段渐变字替代清晰标题 |
| 灰 `#606062` | 正文、非实时说明、适用条件 | 四种实色浅底 | 直接跨越光斑或半透明层；条件缩成不易读的小字 |
| 淡紫 `#B7A2E3` | 可选冷暖补色，局部柔光≤8% | 图形；实色面用深墨 | 与橙色、蓝色一起新增多个强调焦点 |
| 橙色 `#F36600` | 极少量装饰或图表第二标记 | 深墨字；不承载小字 | 白字按钮；把橙色泛化为盈利、奖励或保证信号 |

补充建议：装饰边线 `#DCE7E1`；可操作组件边界 `#81938A`；负向行情字 `#9D333B`。正负号和方向符号与颜色同时出现。橙色不充当负向行情色。任何状态都不能仅靠颜色判断。

### 对比度验收

使用 WCAG 相对亮度公式计算，普通字 ≥4.5:1，大字 ≥3:1；焦点与必要的控件边界 ≥3:1。具体组合见 [contrast.json](evidence/contrast.json)。主要结果在验收报告中列出。

信息文字位于实色白面或确定的浅底。平台柔光中心在右侧，左侧文案区的叠色量较低；验收同时采样实际合成背景，而非只测设计令牌。亮色按钮使用深墨文字并有深绿细边。虹彩边框是装饰，按钮文字和外部焦点仍单独达标。

## 4. 三种渐变配方

以下除已注明的五段色标和柔光带参考参数外，位置、尺寸、透明度和色标均为 **SmartHSB 新建议**。预览 CSS 仅在独立审阅目录使用。批准后在 `home-minpilot.css` 内加首页作用域，不增加旧主题覆盖。

```css
/* 项目建议：移入首页时使用 .home-minpilot 作用域，不直接改共享 :root。 */
.home-minpilot {
  --surface: #FFFFFF; --surface-soft: #F6F6F6;
  --surface-mint: #F1FFF7; --surface-ice: #EEF5FF;
  --grass: #97F05E; --lime: #BFFF37; --mint: #5BFFC3;
  --emerald: #01A66B; --action-blue: #235DFE; --glow-cyan: #00E5E0;
  --ink: #1D1D1F; --body: #606062; --link: #006C45;
  --accent-violet: #B7A2E3; --accent-orange: #F36600;
  --line: #DCE7E1; --control-line: #81938A;
  --ease-enter: cubic-bezier(.22,1,.36,1); /* 建议曲线 */
}

/* 1. 产品舞台。独立绝对定位装饰层，不对正文做 filter。 */
.home-minpilot .product-glow {
  background:
    radial-gradient(ellipse at 85% 22%, #BFFF374D 0%, transparent 43%),
    radial-gradient(ellipse at 68% 48%, #5BFFC366 0%, transparent 45%),
    radial-gradient(ellipse at 80% 88%, #235DFE1F 0%, transparent 44%),
    #FFFFFF;
}
/* 手机：光源随纵向产品位置移动，降低蓝光密度，不增加 blur。 */
@media (max-width: 800px) {
  .home-minpilot .product-glow {
    background:
      radial-gradient(ellipse at 85% 55%, #BFFF3733, transparent 34%),
      radial-gradient(ellipse at 50% 70%, #5BFFC359, transparent 38%),
      radial-gradient(ellipse at 75% 90%, #235DFE17, transparent 34%), #FFFFFF;
  }
}

/* 2. 柔光带。颜色和 .6 来自原站，其余尺寸与 blur 是项目建议。 */
.home-minpilot .soft-band::before {
  content: ''; position: absolute; inset: 25% 10%; pointer-events: none;
  background: linear-gradient(90deg, #BCFFF4, #DDFF90);
  opacity: .6; filter: blur(80px);

/* 1200px 以上舞台：80px；768–1199px：56px；手机：28–36px。 */
```

柔光以容器裁切限制绘制范围，默认静态。普通卡用实色、细边或背景分层。阴影只出现在产品设备及少量悬浮信息；玻璃只留给后续导航或一张浮卡的可选方案。当前审阅稿导航为实色白色，不为了“材质齐全”添加模糊。

### 按钮状态（项目建议）

| 按钮 | 默认 | Hover / focus-visible | Active | Disabled |
| --- | --- | --- | --- | --- |
| 亮绿主行动 | `#BFFF37` / 深墨字 / 深绿 1px 边 | `#97F05E`，箭头 +4px；键盘加蓝色 3px 外环，offset 5px | `#5BFFC3`，文字不移位 | 柔白 / 灰字 / 灰边；真实 disabled，无浮动 |
| 功能蓝 | `#235DFE` / 白字 | `#1849D6` / 白字；相同焦点 | `#123CBA` / 白字 | 同上 |
| 虹彩次行动 | 2px 外壳 / 白内层 / 深墨字 | 内层冰蓝，外部蓝色焦点；不靠彩边表达焦点 | 内层浅薄荷 | 外壳改中性灰边，无彩色点击暗示 |
| 文字链接 | 深绿，下划线或清晰链接结构 | 蓝色、保留下划线和焦点 | 蓝色 | 无目的地不造假链接，改成状态文字 |

文字翻页只作为重点 CTA 的可选处理，整行双层文字，克隆层 `aria-hidden`。当前审阅稿仅实现箭头和颜色反馈，未把文字翻页或遮罩展开写成已实现。减少动效/手动关闭时保留颜色和焦点，停止位移。

## 5. 字体、尺寸与响应式

英文正式方向为 General Sans 气质。**审阅稿实际使用仓库已有 SuisseIntl-Medium + 系统中文黑体**，未下载或重新授权 General Sans。后续如确定使用 General Sans，需先核对来源与授权。中文系统回退为 PingFang SC / Microsoft YaHei；需要跨设备字形一致时再评估 Noto Sans SC 的体积。

标题控制成自然的中文两行，深墨为主，不单独把某个词染成荧光色。数字用 `font-variant-numeric: tabular-nums`。设计稿小尺寸手机画面中的设备屏幕是被缩放的产品示意，屏外保留可读的非实时说明和功能文案；它不承担交易操作。

### 三个重点场景

1. **光门与浅色内容衔接。** 原 HERO 独立保留，后接浅薄荷光白底。沿用“一个账户。打开全球市场。”和现有说明；四类市场计数直接铺在一条分隔线上。解决原光门和浅色内容像两套主题的问题，同时不改已有影像。
2. **平台产品区。** 采用现有“从看见机会，到把握机会”、两项平台说明和下载入口。使用现有网页手机示例中的文字、虚拟资金与报价，按新材质绘制其外部舞台。该示意不是新 APP 截图，也不承诺 APP 将增加白色皮肤。右上分析卡和左下模拟账户卡形成前后层次。解决平台产品面积偏小、信息与产品分离的问题。
3. **市场区。** 原四分类、25 品种、中文名、示例报价和代表图表数据来自当前首页/脚本。Tab 用深绿边线、浅薄荷底及 `aria-selected` 表达选择；列表回到白底。解决亮色冲淡数据层次和手机列表难以浏览的问题。

三个场景的实际文案均出现在审阅稿中。市场和设备旁明确写“非实时/展示示例”，模拟账户写“虚拟资金”，不把上涨示例或设备画面当作收益承诺。
