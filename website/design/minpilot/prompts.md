# SmartHSB × Minpilot 设计提示词

基于 2026-11-11 对 [Minpilot](https://minpilot.webflow.io/) 首页、公开 Style Guide、CSS 与动效配置的检查。完整提取与来源见 [设计规范](spec.md)。

使用方式：后续设计先使用“总提示词”；需要单独深化时追加配色或动效提示词。以下文本是供后续任务使用的指令，本次研究没有执行首页改版。

## 1. 总提示词（可直接复制）

```text
请为 SmartHSB 金融交易产品网站设计一套浅色视觉方案。主要参照 https://minpilot.webflow.io/ 的设计语言：明亮的白色空间、蓝绿柔光、多层产品展示、大字号无衬线标题、圆角白色组件、精细渐变边缘和有节奏的动画。保持接近参考站的视觉气质、层次、组件比例和动效处理，并使用 SmartHSB 的品牌、产品和内容。

这一步先输出可审阅的配色规范、关键区块设计和动效说明，待确定方案后再实施页面。不要把提示词当作修改线上首页的指令。

一、整体方向
全站以浅色为主。以白 #FFFFFF、柔白 #F6F6F6、浅薄荷 #F1FFF7、冰蓝 #EEF5FF 建立底色。原站有黑色区块；本方案将常规内容区转成浅色，通过白/浅灰/浅薄荷/浅蓝交替、产品比例和留白形成节奏。保留明亮、清透、精密的金融科技观感，兼顾金融信息的可信度和可读性。

二、颜色及分工
使用从参考站提取的亮色体系：荧光草绿 #97F05E、柠檬黄绿 #BFFF37、薄荷亮青 #5BFFC3、翡翠绿 #01A66B、电光科技蓝 #235DFE；电光青 #00E5E0 用作局部光晕。深绿 #006C45 用作浅底文字链接，深墨 #1D1D1F 用于标题和正文，#606062 用于辅助说明。淡紫 #B7A2E3、橙色 #F36600 只作少量补色。
以约 75% 白/柔白、15% 浅蓝/浅薄荷、8% 绿青强调、2% 蓝及其他补色为构图起点。这个比例是项目建议。每区块一个主强调色，最多一个辅助色；不同颜色承担不同功能。亮绿和薄荷按钮配深色字，蓝色按钮配白字；检查真实背景上的文字对比度。

三、渐变与材质
参照原站的柔光叠色：用大面积、边界模糊、非对称的薄荷绿、柠檬绿、青和科技蓝光斑，在产品后方形成空间，边缘融入白色。渐变中心靠近产品，正文区域保持平静。可加入极少量淡紫增加冷暖层次。默认静态；不要让整个背景快速流动。
保留一个薄荷至柠檬的柔光区域，原站参考参数为 linear-gradient(90deg, #BCFFF4, #DDFF90)、opacity .6、blur 200px；实际落地按区域和手机性能减小模糊范围。
次按钮可使用 2px 虹彩边框：#FFEAB5 20% → #F2A85D 40% → #8052E4 60% → #2E85EA 80% → #68EFAE 103%，内层白色、胶囊圆角。只用于少量重点轮廓。
产品容器可用白色/轻透明白色、细边和轻阴影。普通信息卡保持实色清晰；玻璃材质只用于导航和少量悬浮卡。避免给每个区块都加同一种渐变、玻璃和阴影。

四、布局与字体
桌面内容宽约 1200–1328px，区块上下留白约 96–120px；手机左右留白 16–20px，区块间隔 56–72px。采用大产品展示、左右分栏、两张宽卡配三张小卡、清晰列表等组合，根据内容选择结构。
英文参考 General Sans 的现代无衬线气质；中文配自然、易读的系统黑体或 Noto Sans SC。中文标题桌面约 56–68px、手机 32–40px；区块标题桌面 40–56px、手机 28–32px。正文 16–18px、行高 1.6–1.75。标题以深墨色为主，控制断行。
普通卡圆角 16–20px，重点产品容器 24–32px，按钮胶囊圆角 999px、高度约 48–52px。产品图占主要视觉面积，少量数据浮卡提供层次；使用 SmartHSB 的真实产品、图表和内容，示例数据明确标注非实时/展示示例。

五、动画
借鉴原站的编排方式：标题、说明、按钮、产品按主次接续呈现；产品和卡片轻移、淡入、轻缩放；按钮文字可翻页式上移，箭头轻移，hover 与键盘焦点均有反馈。
新内容区的建议参数：入场 600–800ms、位移 16–24px、组内交错 60–100ms；按钮 180–300ms；Tab 退出 100–150ms、进入 250–300ms；悬浮卡上下 6–10px，一个往返 5–7s；装饰轨道可参考原站 30s 一圈。不要同时让所有模块循环运动。
原站用 Webflow IX3/GSAP/ScrollTrigger/SplitText；SmartHSB 是原生 HTML/CSS/JS，可用 CSS 与 IntersectionObserver 实现所需效果，不为外观引入 Webflow 运行时。优先动画化 transform/opacity，不持续改变大面积 blur。手机减少装饰运动。
支持 prefers-reduced-motion 与现有 #motion-toggle；关闭时显示最终状态。脚本禁用或失败时内容仍可见。持续动画支持暂停、离屏停止和后台暂停。

六、SmartHSB 边界
保留 #intro-portal 光门 HERO 的门、人物、文案、现有动画时序和逻辑、原视频及底部六机构徽章，不用参考站的手机替换首屏。可按蓝绿浅色方向评估调色，先验证 Canvas 合成、轮廓和文字对比；不能只改背景 CSS 就视为完成浅色适配。不要在光门上再叠一套手机轨道。
保留四类市场的 25 品种（2 贵金属、5 股指、17 外汇、1 能源）、模拟账户、平台功能、监管和资金隔离、支付与保险条件、积分活动、六年奖项、五家媒体、FAQ、运营信息、牌照和风险披露。不编造或扩大任何金额、承诺和资质。
沿用当前首页样式归属 home-minpilot.css；首页改动限定作用域，保留 JavaScript 所依赖的市场标签和面板、.platform-visual、导航及动效开关。不要叠加旧主题文件。

七、输出要求
先交付色板与语义分工、渐变配方、桌面/手机关键画面、区块布局说明和动效表。明确标记原站事实与项目建议，并说明每个关键选择解决什么问题。优先展示光门与浅色内容的衔接、平台产品区和市场区三个场景。按 320/390/768/1024/1440px 检查布局、键盘操作、对比度和减少动效。方案确定后再改页面并按项目发布流程交付。
```

## 2. 配色与渐变专项提示词

```text
请只深化 SmartHSB 的浅色配色和渐变系统，参照 Minpilot 的柔光与亮色关系，不修改页面结构。

底色：#FFFFFF、#F6F6F6、#F1FFF7、#EEF5FF。主亮色：#97F05E、#BFFF37、#5BFFC3、#01A66B；功能蓝 #235DFE；局部光色 #00E5E0。标题 #1D1D1F、正文 #606062、浅底链接 #006C45。每个颜色给出使用位置、搭配底色、文字颜色及禁止混用的情况。

分别给出三种可复用配方：
1. 产品舞台：在白底上叠加偏右的柠檬绿、中央薄荷青、底部浅蓝径向光斑，边缘消散；正文区域保持可读。
2. 柔光带：#BCFFF4 → #DDFF90，约 .6 透明度，独立装饰层；参考原站 blur 200px，给出按容器和手机性能缩减后的值。
3. 细虹彩边框：2px 外壳 + 白色内层胶囊，五段色为 #FFEAB5 / #F2A85D / #8052E4 / #2E85EA / #68EFAE。

提供 CSS 变量、渐变示例和按钮状态。原站首屏柔光是背景图，不要声称某个新写的 CSS 配方就是原站源码。新增径向渐变、透明度和色标均标记为项目建议。保留光门 HERO 构图、视频和动画，只提出调色及衔接方案。输出三个具有实际文案的场景，验证明暗与文字对比。
```

## 3. 动效专项提示词

```text
请为 SmartHSB 浅色内容区定义参照 Minpilot 的动效规范，保留现有光门 HERO 的动画和视频逻辑。

可借鉴的原站事实：卡片淡入+上移 0.7s；数据浮卡单程 1.5s、往返约 3s；轨道旋转 30s；主按钮文字上移 0.3s、白色遮罩展开 0.4s；次按钮文字上移 0.2s；Tab 进入 300ms、退出 100ms。原站的连续浮动和轨道在浏览器中确实运行。

SmartHSB 建议更克制：入场 600–800ms、16–24px、交错 60–100ms；按钮 180–300ms、箭头 4–6px；悬浮卡 6–10px、完整往返 5–7s；一个产品区最多一组持续装饰动画。中文标题以按行接续为主。渐变默认静态，手机关闭非必要循环。

用表格说明触发方式、对象、起止状态、时长、延迟、缓动、是否循环、退出/暂停方式和手机降级。数字 ease 标识未解析时不要编造原站曲线；可将 cubic-bezier(.22,1,.36,1) 标记为建议曲线。

原生 CSS 与 IntersectionObserver 优先。内容默认可见，启用动画只能作为渐进增强；按钮 hover 与 focus-visible 同等反馈；prefers-reduced-motion 或 #motion-toggle 关闭时进入最终静态状态；离屏和后台暂停循环；Tab 和 FAQ 保留键盘语义。只为可操作对象提供点击暗示。
```

## 4. 设计复核提示词

```text
请对 SmartHSB 设计稿进行复核，依据 Minpilot 设计参考和项目边界，只报告具体差距与修改办法。

检查：整体是否由白、柔白、浅蓝、浅薄荷主导；荧光草绿/柠檬黄绿/薄荷青/翡翠绿/科技蓝是否各有角色；柔光是否集中在产品与边缘；是否滥用渐变字、玻璃卡和循环动画；产品是否有足够视觉重量；标题、正文、示例报价和风险条件是否可读。

检查光门 HERO 是否保留构图、门、人物、原文案、视频、动画逻辑和六机构徽章；是否验证浅色调与 Canvas 合成的关系；是否完整保留 25 品种、账户、平台、监管、资金隔离、支付保险条件、积分活动、奖项、媒体、FAQ 和披露。检查 320/390/768/1024/1440px、键盘焦点、Tab 方向键、菜单、FAQ、下载链接和减少动效。

每个问题说明位置、影响、根因与最小有效修改。区分原站实测参数、SmartHSB 新建议和设计稿实际实现；未检查的项目明确标记未检查。
```
