# Minpilot 设计规范提取与 SmartHSB 适配

采集日期：2026-11-11（北京时间）。对象：[Minpilot 首页](https://minpilot.webflow.io/) 与其公开 [Style Guide](https://minpilot.webflow.io/admin/style-guide)。

本报告检查了首页各区块、桌面 1440px / 手机 390px 页面、共享 CSS、Webflow 动效配置及两份柔光 SVG。**“原站实测”是页面或源码中的事实；“适配建议”是为 SmartHSB 制定的新规则。** 没有将参考站的素材或组件代码搬入 SmartHSB。

## 1. 最值得复用的设计逻辑

原站的辨识度来自四层组合：白色空间、蓝绿柔光背景、清晰的产品界面、少量高饱和亮色。大标题和产品演示先建立视觉中心，再用色块、圆角和动画组织信息。

原站并非全浅色：首页的广告卡、业务构建区和页脚使用黑底。SmartHSB 按本次需求改为**整体浅色**，通过白、浅灰、浅薄荷和浅蓝的区块变化保留节奏；亮绿、青和蓝作为明确的视觉锚点。

需要一起复用的关系：

- 浅底承载信息，亮色引导行动；高饱和颜色不铺满全文。
- 渐变集中在产品背后、区块边缘和局部轮廓，正文区域保持平静。
- 真实界面、手机、图表和数据卡占据主要图像位置。
- 大小不同的模块交替出现，避免整页排列相同卡片。
- 动画分为入场、持续装饰、交互反馈，各自有明确用途。

你提到的“柠檬亮青”可拆为两类：`#BFFF37` 是偏黄的亮绿，`#5BFFC3` / `#00E5E0` 是偏青的亮色。分别分配角色，比混成一个名称更容易稳定复现。

### SmartHSB 的浅色配色规则（建议）

- 以约 **75% 白/柔白 + 15% 浅蓝/浅薄荷 + 8% 绿/青强调 + 2% 蓝及其他补色** 为起点。这是设计面积分配建议，不是原站像素统计。
- 每个区块确定一个主强调色，最多加一个辅助色。全站保留完整色系，单个模块控制颜色数量。
- 新增浅底令牌：浅薄荷 `#F1FFF7`、冰蓝 `#EEF5FF`、柔和边线 `#DCE7E1`。这三个值属于本项目建议。
- 亮绿、柠檬绿、薄荷青按钮使用深墨色文字；蓝色按钮可使用白字。不要默认在翡翠绿上使用小号白字。
- 渐变和光晕不承担信息状态；涨跌、选中、错误等状态同时使用文字或图形标识。
- 普通文字对比度至少 4.5:1，大文字至少 3:1；在实际渐变最不利的位置测量。这里是交付要求，不是对原站的合规结论。

## 3. 渐变的真实做法

### 3.1 首屏：背景图中的柔光，而非实时流体动画

**原站实测：** `.home-hero-area` 通过 WebP 背景图承载首屏的蓝、绿、青和淡紫柔光。不能把截图中柔和的颜色变化直接解释为 CSS 流体动画。

**视觉规则：** 大色域、低清晰度边界、色光相互叠加，外围向白色消散；亮度中心靠近产品，主文案附近留出相对安静的浅色面。

**适配建议：** 用原创的多层径向渐变重建这种空间关系，默认静态。下面的角度、位置、透明度和色标是建议配方，不是原站首屏 CSS。

```css
.product-glow {
  background:
    radial-gradient(ellipse at 78% 22%, #BFFF3766 0%, transparent 48%),
    radial-gradient(ellipse at 52% 45%, #5BFFC366 0%, transparent 48%),
    radial-gradient(ellipse at 84% 78%, #235DFE26 0%, transparent 52%),
    radial-gradient(ellipse at 34% 80%, #B7A2E329 0%, transparent 46%),
    #FFFFFF;
}
```

### 3.2 薄荷至柠檬的模糊色层

**原站实测：** `.integrations-color-shape` 使用横向渐变 `#BCFFF4 → #DDFF90`，`opacity: .6`，`filter: blur(200px)`；桌面高度为 465px。原站还使用柔光 SVG：多个不同色块叠放，`feGaussianBlur` 的 `stdDeviation` 为 66.6667 / 100，单位属于 SVG 坐标系，不能直接等同所有屏幕上的 CSS 像素。

```css
/* 原站关键参数的简写；不包含原站完整布局 */
.mint-lime-halo {
  background: linear-gradient(90deg, #BCFFF4, #DDFF90);
  opacity: .6;
  filter: blur(200px);
}
```

**适配建议：** 装饰色层放在产品后方，用独立层限制范围；手机先缩小光斑面积与模糊半径。避免对整块正文或整页使用 filter，也不要在滚动时持续动画化大面积 blur。

### 3.3 2px 虹彩边框

**原站实测：** 次按钮外壳使用五段渐变，外层 `padding: 2px`、胶囊圆角；内部实色面遮住中心，留下纤细彩边。

```css
/* 原站配色与色标 */
.iridescent-rim {
  padding: 2px;
  border-radius: 999px;
  background: linear-gradient(
    180deg, #FFEAB5 20%, #F2A85D 40%,
    #8052E4 60%, #2E85EA 80%, #68EFAE 103%
  );
}

/* SmartHSB 内层实现建议 */
.iridescent-rim > a {
  display: block;
  padding: 12px 24px;
  border-radius: inherit;
  background: #FFFFFF;
  color: #1D1D1F;
}
```

用途：一个次级行动或一个重点模块的轮廓。不要让每张卡片都出现彩边，否则页面会失去主次。

### 3.4 深蓝至亮色的边缘光

**原站实测：** 广告卡的外壳使用方向不同的渐变，如 `135deg: #04003C → #97F05E`、`270deg: #04003C → #00E5E0`。部分卡片只在顶部或底部露出约 6px 色带，内部仍是清晰的实色信息面。

**适配建议：** 浅色站保留“外壳渐变 + 内层白卡”的结构，用于一个重点产品展示；不要把深蓝直接铺满正文面。

### 3.5 材质、阴影与过渡

原站同时使用实色白卡和局部玻璃材质。部分深底卡使用白色 10% 的表面、浅色细边与 `backdrop-filter: blur(50px)`。不要将玻璃效果推广到所有卡片。

SmartHSB 建议用白色或轻透明白色承载正文，用轻阴影表现产品图层；只在导航、少量悬浮信息卡使用透明材质。静态卡优先依靠底色差、边线和留白区分。

## 5. 原站动效清单

原站当前使用 **Webflow Interactions 3、GSAP 3.15.0、ScrollTrigger 和 SplitText**。共享脚本含多页面配置；下面选择与首页相关的规则。配置中未明确声明的时长，不补写为“实测”。

| 动效 | 原站配置与作用 | 采纳方式 |
| --- | --- | --- |
| 首屏依次入场 | 提示胶囊起点 0s；标题从 0.08s 起、交错 0.1s；产品从 0.12s 起、缩放 0.5→1、显式时长 0.7s；说明从 0.72s 起；按钮 0.99s；机构标识 1.23s | 复用先后秩序；不覆盖 SmartHSB 光门现有时序 |
| 区块标题分字 | 透明度 0→1、x 10px→0、scale 1.4→1，整段交错量 0.5s；说明按行接续 | 中文优先按行入场，减少逐字缩放造成的阅读负担 |
| 特征卡入场 | 顶部进入视口 95% 处触发；opacity 0→1、y 30%→0；0.7s | 保留一次性入场的节奏，缩小位移 |
| 悬浮数据卡 | 两张卡方向相反，y 20%→0 / -20%→0；单程 1.5s，repeat -1、yoyo true | 一个往返约 3s；本项目建议更慢、更小幅度 |
| 轨道旋转 | 360°→0°，30s，无限循环 | 只用于装饰层，提供暂停并在离屏时停止 |
| Logo 横移 | x 0→-100%，20s，无限循环 | 若采用需可暂停；现有六机构徽章不自动改为跑马灯 |
| 评价墙滚动 | 不同列向上/向下，30s，无限循环 | SmartHSB 无必要时用静态评价或媒体列表 |
| 超大文字横移 | x 0→-100%，60s，无限循环 | 可不采用；金融产品信息优先可读 |
| 主按钮悬停 | 文字 y 0→-100%，0.3s、逐字交错 0.02s；白色遮罩 scale 0→1，0.4s；箭头右移 0.4s；移出反向播放 | 适合重点 CTA；键盘 focus-visible 同样反馈 |
| 次按钮悬停 | 文字翻页式上移，0.2s、交错 0.02s；移出反向播放 | 中文可直接做整行双层文字切换 |
| 文本链接箭头 | 悬停旋转 0→-45° | 可改成轻微位移，统一全站一种规则 |
| 产品 Tab | Webflow 标记为进入 300ms、退出 100ms，easing 为 ease；实际点击能切换选中状态 | 保留短暂交叉淡入，提供方向键操作 |
| 滚动联动 CTA 图 | scale 0.5→1，scrub 0.8；范围 top bottom→30% 50% | 只在确有空间关系时使用，不扩展成整页滚动劫持 |
| 背景视频 | 存在 muted / loop / autoplay 的视频元素，以及减少动效时的后备图片逻辑 | 属于原站配置；本次浏览器读取为 paused，未将其记为已播放成功 |

浏览器间隔 1 秒采样时，轨道、浮卡和 Logo 的 transform 发生变化，确认这些不是仅留在文件中的静态配置。实际检查了按钮 hover 与产品 Tab 切换。没有把未解码成功的视频记为现场播放证据。

### SmartHSB 动效参数（建议，不是原站数值）

- 标题/产品一次性入场：600–800ms，位移 16–24px，组内交错 60–100ms。
- 按钮反馈：180–300ms，箭头位移 4–6px；必要时借用原站文字翻页。
- Tab 内容：退出 100–150ms，进入 250–300ms；切换时避免容器高度突跳。
- 悬浮卡：上下 6–10px，一个往返 5–7s；每个产品场景最多一组持续装饰动画。
- 原创柔光默认静态。需要呼吸感时只缓慢改变 transform / opacity，周期 16–24s；手机关闭。
- 入场可用 `cubic-bezier(.22, 1, .36, 1)`，持续悬浮可用 ease-in-out。这些曲线是建议值，未将源码中的数字 ease 标识推断为具体贝塞尔曲线。
- `prefers-reduced-motion: reduce` 或 `#motion-toggle` 关闭时，立即呈现最终状态，停止循环与滚动联动。脚本失败或禁用时，正文仍可见。
- 只给按钮、链接等可操作对象添加 hover / focus 反馈。不能让静态卡片看起来可以点击。

### 光门 HERO 的浅色边界

当前项目的 `intro-portal.css` 和 Canvas 视频合成均围绕深底设计。浅色方案应评估背景与合成后的门、人物、雾的对比，**不能仅修改一个 CSS 背景值就宣称完成**。本轮只提出配色方向；后续保留构图、内容、时序、动画逻辑及原视频，在允许的调色范围内验证。光门周围不能再叠一套参考站手机轨道构图。

## 7. 后续设计验收

1. 第一眼是明亮的蓝绿金融科技产品；白色和浅色面占主导。
2. 荧光草绿、柠檬黄绿、薄荷青、翡翠绿、科技蓝均有明确角色，单个模块控制主辅色。
3. 至少一处产品背景体现柔光叠色；次按钮可使用一次细虹彩边框。
4. 标题、正文、图表、产品图有清晰层次；风险和限定条件保持易读。
5. 产品图、品种和功能均来自 SmartHSB，示例数据标注非实时/展示示例。
6. 保留四类市场共 25 品种、模拟账户、平台、监管和资金隔离、支付与保险条件、积分活动、六年奖项、五家媒体、FAQ、运营信息、牌照及风险披露。
7. 保留市场标签/面板、`.platform-visual`、导航与 `#motion-toggle` 等调用关系，改结构时检查脚本。
8. 320、390、768、1024、1440px 无横向溢出、遮挡、重要文字截断；方向键、键盘焦点、FAQ、菜单和下载链接可用。
9. 关闭动效或脚本时仍能读到完整内容；离屏和后台停止持续动画。
10. 使用原站的视觉规则与节奏，但交付 SmartHSB 自己的品牌、产品和文案。
