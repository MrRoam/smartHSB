先装哪个：两条交易路径

SmartHSB 体系下有两个常用客户端，职责不同：

客户端主要用途获取渠道
SmartHSB APP注册开户、身份验证（KYC）、入金出金、账户与安全管理下载中心 / App Store / Google Play
MetaTrader 5专业看盘、技术分析、下单交易App Store / Google Play / MetaQuotes 官网

推荐顺序：先在本站或 APP 完成注册开户，再安装 MT5 登录交易。注册环节通过站内或 APP 进行，之后在 MT5 中登录 HSB 交易服务器即可开始交易。

Android 安装 MT5（7 步）

  1. 打开 Google Play Store——在主屏或应用列表中找到 Play Store 图标；也可以从下载中心获取安装包。
  2. 搜索 MetaTrader 5——在顶部搜索框输入「MetaTrader 5」，点击搜索。
  3. 选择应用——在结果中点开 MetaTrader 5 的详情页，注意核对开发者信息。
  4. 点击安装——下载与安装过程需要稳定的网络连接。
  5. 打开应用——安装完成后点击「打开」。
  6. 登录或注册——首次打开会要求登录交易账户；还没有账号的，先回本站或 APP 完成注册。
  7. 选择交易服务器——在服务器列表中选择 HSB 的交易服务器，登录成功后即可看行情、下订单、管理持仓。

iOS 安装 MT5

iPhone / iPad 的安装流程与 Android 基本一致，仅前两步不同：

  1. 打开 App Store，搜索「MetaTrader 5」；
  2. 点击获取并通过 Face ID / Touch ID 确认下载；
  3. 后续「打开 → 登录 → 选择 HSB 交易服务器」与 Android 相同。

提示：部分地区 App Store 账号区域可能影响搜索结果，如找不到应用，可切换账号区域或从下载中心获取指引。

电脑端安装 MT5

桌面端适合多图表分析与长时间盯盘，安装共 4 步：

  1. 下载安装包——从下载中心或 MetaQuotes 官网获取 MT5 安装程序，Windows 与 macOS 请选择对应版本；
  2. 运行安装并同意许可协议——双击安装文件，仔细阅读许可协议后按提示完成安装；
  3. 打开 MT5——安装完成后启动应用；
  4. 登录账户——菜单栏 文件（File）→ 登录交易账户（Login to Trade Account），输入登录 ID 与密码，选择 HSB 交易服务器后点击「OK」。

桌面端的优势：屏幕更大、可同时打开多张图表，38 个内置技术指标与 21 种时间框架更适合做深度分析。

登录：账号与交易服务器

MT5 登录需要三样东西：登录 ID、密码、交易服务器。

  • 登录 ID 与密码来自注册：在 SmartHSB 网站或 APP 完成注册后即可获得；
  • 服务器在登录界面下拉列表中选择 HSB 的交易服务器；
  • 模拟账户与真实账户分别对应不同的服务器条目，登录时注意区分；
  • 忘记密码请在 APP「安全」设置中重置，详见 账户管理 →。

安全提示：请只从官方渠道下载客户端。MT5 登录凭据等同于资金账户钥匙，不要告知他人或在非官方工具中填写。

卸载 MT5

平台步骤
Windows开始菜单 → 找到 MetaTrader 5 文件夹 → 运行 Uninstall → 按提示确认完成
macOS打开 Finder → 应用程序文件夹 → 选中 MetaTrader 5 按 Command + Delete → 确认删除
Android / iOS长按桌面图标 → 选择卸载 / 移除 App → 确认即可

卸载客户端不会删除交易账户。重新安装后用原登录 ID 与密码登录即可，历史持仓与记录以服务器数据为准。
