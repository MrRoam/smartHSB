01什么情况用银行转账

银行转账是把资金直接汇到隔离账户的传统方式，适合单笔金额较大、或习惯使用网银与柜台办理的客户。与其他两种方式的差异：

方式到账是否需要上传凭证适合场景
银行转账最长 15 分钟（需验证）需要（用 BCA 账户转账并填备注可免）大额入金、习惯银行渠道
虚拟账户 VA即时，通常 <1 分钟不需要常用、希望自动到账
电子钱包 / QRIS即时，自动入账不需要小额、手机操作

03标准流程 3 步

  1. 在 APP 内发起入金——登录后进入 Deposit 菜单，选择 Bank Transfer，再选择您要用的银行；输入入金金额后，页面会显示收款账号、应转金额与备注代码（Berita / 参考码），请记录下来。
  2. 从本人银行账户转账——通过手机银行、网银或 ATM 转到上一步显示的账号，金额须与 APP 内填写的一致，备注栏填入 APP 给出的参考码。
  3. 回到 APP 上传凭证——在 APP 内点击上传付款凭证（Unggah Bukti Pembayaran），提交截图或 ATM 凭条照片（PNG / JPG，≤5MB），完成后等待验证。

转账必须由您本人名下的银行账户发起。来自他人账户的转账与现金存款一律无法处理，资金将按原路退回。

04BCA 转账路径

BCA Mobile / myBCA

  1. 登录 BCA Mobile，选择 Transfer → 到 BCA 账户（ke Rekening BCA）；
  2. 输入收款账号 0353255786，核对户名显示 PT Handal Semesta Berjangka；
  3. 输入与 APP 一致的金额；
  4. 在备注栏（Berita）填入 APP 给出的参考码；若填写您的 User ID 与 Login ID，用 BCA 账户转账可自动入账，无需上传凭证或等待人工验证；
  5. 确认完成，保存转账凭证截图。

ATM BCA

  1. 插卡并输入 PIN → 其他交易（Transaksi Lainnya）→ 转账（Transfer）→ 到 BCA 账户；
  2. 输入收款账号与金额并确认；
  3. 妥善保存凭条，回到 APP 上传凭证照片。

05Mandiri 转账路径

Livin' by Mandiri

  1. 登录 Livin'，选择转账（Transfer）→ 到 Mandiri 账户（Antar Rekening Mandiri）；
  2. 输入收款账号 1220009928501，核对户名；
  3. 输入金额与备注参考码，确认后保存凭证。

ATM Mandiri / 他行 ATM

  1. ATM Mandiri：插卡 → 输入 PIN → 转账 → 到 Mandiri 账户，输入账号与金额；
  2. 他行 ATM：选择跨行转账（Transfer ke Bank Lain），输入 Mandiri 银行代码 008 + 收款账号；
  3. 确认户名与金额无误后完成，保存凭条。

06BNI 转账路径

BNI Mobile Banking

  1. 登录 BNI Mobile，选择转账（Transfer）→ 到 BNI 账户；
  2. 输入收款账号 2019123122，核对户名；
  3. 输入金额与备注参考码，确认并保存凭证。

ATM BNI / 他行 ATM

  1. ATM BNI：插卡 → 输入 PIN → 转账 → 到 BNI 账户，输入账号与金额；
  2. 他行 ATM：选择跨行转账，输入 BNI 银行代码 009 + 收款账号；
  3. 确认信息后完成交易，保存凭条。

07到账时间与处理规则

项目规则
最低入金Rp400.000（约 $25）
手续费免费，由 HSB 承担（银行端网络费用以各银行为准）
币种IDR（印尼盾）
验证时长最长 15 分钟；用 BCA 账户转账且备注填写 User ID 与 Login ID 时自动入账
服务时间24 小时；BNI / Mandiri 在每日约 23:00–01:00 WIB 的银行维护窗口内会顺延
首次入金需经 HSB 客户经理（Wakil Pialang）团队电话确认后入账，确认时间为 08:00–22:00 WIB
再次入金（Top Up）已完成过首次入金的账户，24 小时自动处理，无需等待电话确认

以上时间为 WIB（UTC+7）。若超过 15 分钟仍未到账，先在 APP 内确认凭证是否已成功上传，再联系客服核对。
